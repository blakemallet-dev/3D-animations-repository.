# Ornate Stamp — Uncolored Textured Model

This package contains the user-supplied ornate stamp mesh with a uniform neutral-gray material and retained engraved/worn surface relief.

## Files

- `ornate_stamp_uncolored_textured.blend` — editable Blender 5.2.1 project with the packed texture source.
- `ornate_stamp_uncolored_textured.glb` — portable mesh export for compatible 3D software and web viewers.
- `preview.png` — reference preview render.

The Blender project contains no light objects. Open it in Material Preview mode to inspect the surface texture.
